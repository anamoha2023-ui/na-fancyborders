# na-fancyborders

**Custom artistic borders and frames for educational documents and magazines.**

## Description
The `na-fancyborders` package provides a collection of professional and artistic geometric designs created using TikZ. These borders are specifically designed for educational materials, certificates, and mathematical magazines (such as "Al-Khalil").

## Features
- Support for **XeLaTeX**.
- Fully compatible with **Arabic typesetting** (using polyglossia).
- Professional geometric frames that do not overlap with student text.
- Easy to use with standard LaTeX document classes.

## Installation
For a manual installation:
1. Download the `na-fancyborders.sty` file.
2. Place it in the same directory as your main `.tex` file (Flat tree structure).
3. Add `\usepackage{na-fancyborders}` to your document preamble.
